# 📊 Power BI Dashboard Project

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze and visualize data effectively. It helps in understanding key metrics, trends, and performance insights through dynamic visuals.

---

## 🎯 Objectives

* To transform raw data into meaningful insights
* To build interactive dashboards using Power BI
* To support data-driven decision-making

---

## 📊 Features

* Interactive dashboards with slicers and filters
* KPI cards for quick performance tracking
* Visualizations including bar charts, pie charts, and tables
* Easy-to-understand layout for better analysis

---

## 🛠 Tools & Technologies

* Power BI
* Microsoft Excel (Dataset)

---

## 📈 Key Insights

* Identified trends and patterns in data
* Compared performance across categories
* Provided clear and actionable insights
